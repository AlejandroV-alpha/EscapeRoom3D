# 🎮 Escape Room 3D

### 🧩 Proyecto colaborativo de desarrollo de videojuegos

Proyecto de laboratorio desarrollado con **Git, GitHub, Visual Studio Code y Unity**, enfocado en el trabajo colaborativo, el control de versiones y el desarrollo de un videojuego de escape en 3D.

## 🎯 Objetivo

Desarrollar un videojuego de **Escape Room en 3D**, donde el jugador deberá explorar una habitación, descubrir pistas y resolver desafíos para conseguir escapar.

---

## 🛠️ Tecnologías utilizadas

- **Unity** — Motor de desarrollo del videojuego.
- **C#** — Lenguaje de programación.
- **Git** — Control de versiones.
- **GitHub** — Repositorio y colaboración.
- **Visual Studio Code** — Editor de código.
